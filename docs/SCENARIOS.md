# 选址场景定义与因子体系

> **本文件已于 2026-09-10 按实际实现重写。** 原 S1–S5「业务场景」口径（建设项目/公服设施/新能源/矿业权/生态修复）
> 已废弃 —— 实际系统改为**国民经济行业 10 大门类**。**申报书、视频、答辩一律以本文件为准。**
>
> 代码即事实来源：`backend/app/services/scenarios.py`（模板）、`backend/app/services/suitability.py`（算法）。
> 本文件与两者不一致时，以代码为准，并回来修本文件。

## 一、设计原则

**一套引擎，多套参数模板。** 新增行业门类 = 新增一个模板，不改算法代码。

系统面向**要素保障 / 格局优化**（可延伸至耕地保护、矿业发展、生态修复），
把「选址」抽象为统一流程，行业差异全部收敛到三处参数：

1. **硬约束集合**（该行业不能碰什么）
2. **缓冲距离**（离多远才安全）
3. **维度权重**（该行业最在意什么）

## 二、统一选址流程（对齐后端实际实现）

```
① 候选池   控规工业用地（regulated-industrial，145 个图斑）∩ 研究区
      ↓
② 硬约束   布尔一票否决：命中即剔除（生态红线、永久基本农田、河湖管理范围…）
           带缓冲的约束先在 EPSG:4525 投影下做 buffer，再判相交
      ↓
③ 面积筛选 最小面积 min_area_ha
           + 用地规模区间 [目标×(1−容差), 目标×(1+容差)]（仅用户提到占地面积时生效）
           + 结果为空时自动放宽兜底，并在返回说明中如实交代
      ↓
④ 因子量测 五维统一因子，全部来自真实空间关系（见 §四）
      ↓
⑤ 组合赋权 前端偏好权重 > AHP×α + 熵权×(1−α)，α 默认 0.5
      ↓
⑥ 排序     TOPSIS（默认）/ 多元回归 / K-Means 聚类优先
      ↓
⑦ 输出     Top-N 候选地块 + 权重 ±20% 敏感性诊断 + 如实说明数据缺口
```

> ⚠️ **候选池固定为控规工业用地**。其他门类（如采矿业、水利环境业）在真实业务中应有各自的
> 候选池图层，当前因**数据可得性**统一用控规工业用地演示，申报书中须如实说明。

### 门类设计意图

- **B 采矿业**：平衡资源禀赋与生态约束，居民点 300m 避让（爆破振动）。
- **C1 消费品制造**：劳动力密集、贴近城镇市场，约束相对宽松。
- **C2 原材料与中间品制造**：重化工，**居民点 500m**、饮用水源 0 容忍，防护距离最严。
- **C3 装备制造**：用地规模大、物流与产业链配套要求高。
- **D 能源与公用事业**：邻避效应强，**居民点 500m**，且须避开行洪区与机场净空。
- **E 建筑业**：施工基地噪声扬尘敏感，居民点 300m。
- **G 交通物流**：紧邻高速出入口/货运站，物流可达性权重高。
- **I 信息技术服务**：电力与网络保障，避开地质灾害与行洪区。
- **M 科技服务**：环境安静，避开噪声源与地质灾害。
- **N 环境与公共设施**：邻避最强，居民点 500m + 饮用水源 + 行洪区 + 地质灾害四重避让。

## 四、五维因子（10 个门类统一）

所有门类共用同一套 5 个因子，得分区间 0–100。**差异只体现在权重**，不体现在因子本身。

| 因子 ID | 名称 | 方向 | 量算口径（真实空间关系） |
|---|---|---|---|
| `urban_planning` | 城市规划 | + | 城镇开发边界内：`60 + 规整度×25 + min(1, 面积/10)×15`；<br>边界外：上述形态规模分 **× 0.55**（严格低于界内基准，防止"离边界越近分越高"的逻辑倒挂） |
| `transport` | 交通物流 | + | 到{生产性服务点位、高速出入口、货运场站}的最近距离 `d`，<br>`100·exp(−d/1500)`，下限 35 |
| `industry` | 产业协同 | + | `0.5×(园区内=100，否则 100·exp(−d_园区/1200)，下限 20)`<br>`+ 0.5×(100·exp(−d_现状工业/600)，下限 0)` |
| `infrastructure` | 基础配套 | + | 到城市黄线的最近距离 `d`，`100·exp(−d/900)`，下限 35 |
| `cost` | 建造成本 | − | `8 + 45×规整度 + 45×min(面积/8, 1)`（规模效应：面积越大单位成本越低） |

**规整度**采用 Polsby-Popper 指数 `4πA / P²`，圆形 = 1，越接近 1 越规整（利于集约布局）。

> 距离衰减形式 `score = 100·exp(−d/d0)`，`d0` 为各因子特征尺度（1500 / 1200 / 900 m），
> 并设得分下限，避免远距离地块被拉成负分。**所有距离与面积一律在 EPSG:4525 投影下量算。**

### 权重来源

`权重 = 前端「选址偏好」 > AHP×α + 熵权×(1−α)`

- **AHP（层次分析法）**：主观权重，体现行业 Know-how，模板内置。
- **熵权法**：客观权重，反映各因子在候选集内的信息量（离散度越大权重越高）。
- **α 默认 0.5**，前端「选址偏好」三档（在意 5 / 一般 3 / 不在意 1）归一化后直接作为权重输入。

## 五、排序算法（三选一）

| 算法 | 原理 | 适用 |
|---|---|---|
| **TOPSIS**（默认） | 逼近理想解排序，`Cᵢ = Dᵢ⁻ / (Dᵢ⁺ + Dᵢ⁻)` | 综合评价，竞赛演示推荐 |
| **多元回归** | 以权重为先验系数的线性加权 `Ŷ = Σ wᵢ·Xᵢ` | 直观可解释，需要加性打分时 |
| **K-Means 聚类** | 因子 z-score 标准化后聚 3 类，**聚类优先 + 类内按得分降序** | 需要"优先开发/条件适合/储备备用"分组时 |

> 注：K-Means 的聚类**只影响排序，不污染得分**——得分仍取 TOPSIS 贴近度，
> 否则组间量级差会把 Top-N 得分压成清一色的 96 分，失去区分度。

**敏感性诊断**：输出权重 ±20% 扰动下 Top-N 的最低重合率与最敏感因子，用于论证结论稳健性。

下表说明**模板里写了、但库里没有图层数据**的约束。引擎会跳过并**在返回说明中逐条列明**，不静默忽略。

| 饮用水源保护区 | — | ❌ **缺图层**，未参与 |
| 地质灾害高易发区 | — | ❌ **缺图层**，未参与 |
| 行洪区 | — | ❌ **缺图层**，未参与 |
| 机场净空/限高区 | — | ❌ **缺图层**，未参与 |
| 噪声/污染源防护 | — | ❌ **缺图层**，未参与 |

**两处代用说明（申报书须交代）**：
- 「河湖管理范围」用 `blue-line`（城市蓝线，水域控制线）代理；
- 「高速/铁路安全保护距离」用 `road-network` 代理 —— 但路网**含全部等级道路**，
  若一律加 100 m 缓冲会把 145 个候选图斑剔到只剩 3 个，属于**把约束用错**，
  故默认不启用，需显式传入 `constraints` 才参与一票否决。

## 八、申报书写作提示

1. **场景口径写"10 个国民经济行业门类"**，不要写 S1–S5。
2. **候选池与约束的数据缺口要主动交代**（§六）——这体现数据合规意识，比藏着更好。
3. 创新点可用：**硬约束一票否决 + 五维统一因子 + AHP/熵权组合赋权 + 三算法可选 + 权重敏感性分析**。
4. 避免宣称"AI 自动识别最优地块"这类绝对化表述——系统是**辅助决策**，
   结论须由规划专业人员复核。
