# 选址场景定义与因子体系

> 本文件定义"多场景"到底是哪几个场景、每个场景的约束与因子。
> 系统的设计目标是：**一套引擎，多套参数模板**，而不是为每个场景写一套代码。

## 一、统一选址流程（所有场景共用）

```
① 确定选址类型 → ② 加载该类型参数模板（约束层 + 因子层 + 权重）
   → ③ 研究区网格化 → ④ 硬约束过滤（布尔，一票否决）
   → ⑤ 软因子标准化（0–100）→ ⑥ 组合赋权 → ⑦ 适宜性打分
   → ⑧ 聚类生成候选地块 → ⑨ 按面积/形状/得分排序取 Top-N
   → ⑩ AI 生成论证报告 → ⑪ 一张图可视化 / 成果导出
```

## 二、场景模板

### S1 建设项目用地选址（要素保障）—— 主打场景
- **目标**：为拟建项目寻找合规、集约、低成本的可用地块。
- **硬约束**：永久基本农田、生态保护红线、河湖管理范围、地质灾害高易发区、已建设用地、道路/铁路/管线安全保护距离、文物保护区。
- **软因子**：坡度（越平越好）、与现状道路距离（越近越好）、与城镇开发边界关系（集中建设区内优先）、土规/城规符合性、地块完整度（形状规整度）、拆迁成本代理指标（现状建筑密度，越低越好）。
- **输出**：Top-N 候选地块 + 合规性说明 + 面积/坐标。

### S2 公共服务设施选址（格局优化 —— 学校/医院/养老/消防）
- **目标**：**覆盖最大化 + 公平性**，而非单块地最优。
- **硬约束**：同 S1 的禁建要素 + 噪声/污染源避让（医院、学校）。
- **软因子**：人口密度（正）、现状同类设施服务缺口（正）、路网可达性（正）、与已有同类设施距离（适度负，避免过度集中）、公共交通站点距离（正）。
- **输出**：候选点位 + 服务范围（等时圈/缓冲区）+ 覆盖率提升量化。

### S3 新能源与充换电设施选址（格局优化 / 双碳）
- **目标**：光伏/风电/储能/充电站落位。
- **硬约束**：生态红线、基本农田、行洪区、机场净空、军事/航空限高。
- **软因子**：太阳辐射量/风功率密度（正）、坡度坡向（正）、并网距离（负）、道路可达（正）、土地成本代理（负）。
- **输出**：可装机容量估算 + 候选地块排序。

### S4 矿业权 / 砂石土矿选址（矿业发展）
- **目标**：在资源禀赋与生态约束间取平衡。
- **硬约束**：生态红线、基本农田、城镇开发边界、饮用水源保护区、自然保护区、居民点安全距离（爆破振动）。
- **软因子**：矿体/砂石资源潜力（正）、覆盖层厚度（负）、运输距离（负）、与已有矿权重叠（负）、生态修复难度（负）。
- **输出**：候选区块 + 环境敏感点距离核查表。

### S5 生态修复 / 补充耕地选址（生态修复 / 耕地保护）
- **目标**：找出最值得修、最容易修、修完效益最大的地块。
- **硬约束**：不得在生态红线内做开发型修复、不得破坏原生林草。
- **软因子**：生态退化程度（正）、土壤污染程度（正）、集中连片度（正）、坡度可治理性、水源保障、与现有生态廊道连通性（正）。
- **输出**：修复优先序 + 连片度分析。

> **9-15 提交范围：S1 必须完整可跑，S2 至少可演示，S3–S5 以"参数模板 + 演示截图"形式体现多场景能力。**

## 三、因子与权重方法

1. **标准化**：正向/负向/区间型因子统一映射到 0–100（线性或分段函数）。
2. **赋权**：
   - **AHP 层次分析法**（主观，专家/政策导向）——体现行业 Know-how。
   - **熵权法**（客观，数据驱动）——体现数据适应性。
   - **组合权重**：`W = α·W_ahp + (1-α)·W_entropy`，α 默认 0.5，前端可调。
   - **一致性检验**：AHP 需通过 CR < 0.1，否则提示重填。
3. **敏感性分析**：权重扰动 ±20%，观察 Top-N 排序稳定性（申报书创新点素材）。

## 四、约束缓冲距离默认值（可在前端调）

| 约束 | 默认缓冲 | 依据 |
|---|---|---|
| 永久基本农田 | 0 m（一票否决，不缓冲） | 法定禁止占用 |
| 生态保护红线 | 0 m（一票否决） | 法定禁止 |
| 河湖管理范围 | 30 m | 河道管理 |
| 地质灾害高易发区 | 100 m | 安全避让 |
| 农村居民点（矿/工业） | 300 m | 噪声与安全 |
| 高速公路/铁路 | 100 m | 安全保护距离 |
| 高压走廊 | 依电压等级 | 电力设施保护 |

> ⚠️ 以上默认值须在申报书与演示中注明为**可配置参数**，实际项目应以现行法规与地方规定为准。
