# 赛事规则与评分口径

> 摘自《桂自然资办〔2026〕86 号：2026 年 AI+国土空间治理创新应用大赛工作方案》

## 一、赛事定位

- 主题：**数智自然·壮美广西**
- 主办：广西壮族自治区自然资源厅
- 结合广西"人工智能+"自然资源**"一张图"**建设内容
- 坚持**开门办赛、立足实战应用**，强化技术落地与成果转化

## 二、赛道与方向

两个赛道：高校 / 企事业单位。五个方向：

| 编号 | 方向 | 责任处室 | 本项目归属 |
|---|---|---|---|
| 一 | 智能感知（装备、北斗、无人机） | 测绘处 | |
| 二 | 智能解译（遥感影像解译） | 调查监测处 | |
| 三 | 数据治理（高质量数据集） | 调查监测处 | |
| 四 | **数智场景（智能体、系统平台案例）** | **规划处** | ✅ **本项目** |
| 五 | 数据安全 | 地信处 | |

**数智场景重点方向**：要素保障、格局优化、耕地保护、矿业发展、资产管理、生态修复、"一张图"建设、综合科考、行业科普。

→ 本项目"多场景智慧选址系统"主攻 **要素保障 + 格局优化**，可延伸至耕地保护、矿业发展、生态修复。

## 三、初赛评分维度（线上评审，9.16–10.31）

1. **项目创新性**
2. **落地可行性**
3. **行业应用价值**
4. **社会价值**
5. **项目完整度**

→ 每一项都要在申报书和演示中**显式对应**，不能只写技术。

## 四、决赛（11 月上旬，南宁，现场答辩）

需阐述：应用场景、操作步骤、技术亮点、解决痛点、取得效果；
并现场回答：技术原理、研发难点、市场竞争力。

→ 演示必须**可现场操作**，不能只放视频。系统要能离线跑。

## 五、参赛硬性要求

- 须具备在**广西或东盟国家**落地的可行性
- 拥有**合法授权使用的知识产权**
- 对所有信息准确性真实性负责，**弄虚作假即取消资格**
- 鼓励提交视频、图片、模型、展示链接
- 视频 **≤3 分钟**；图片 jpg/jpeg/png、**≤5M**、**300dpi**

## 六、提交材料

1. 参赛团队基本信息表（附件 1）—— **PDF 盖章扫描件**
2. 项目申报书（附件 2）—— **PDF**
3. 申报主体责任声明（附件 3）—— **PDF 盖章扫描件**
4. 可选加分：视频、图片、产品模型、说明文档、展示链接、知识产权证明

独立团队需所在单位（或二级学院/单位）**审核盖章**；联合团队需**所有**参与单位盖章。

## 七、申报书字数限制（严格）

| 章节 | 上限 |
|---|---|
| 一、项目概述（背景 / 核心优势） | 300 / 500 字 |
| 二、需求分析 | 800 字 |
| 三、解决方案（方案/功能/场景/创新点） | 1500 字 |
| 四、应用价值 | 800 字 |
| 五、服务模式（市场/投资/可持续性） | 1500 字 |
| 六、可行性与应用价值（落地/推广） | 1500 字 |

→ 总计约 7000 字上限，**写作前先列提纲分配字数**，超字数会被扣分。

## 八、成果转化激励（申报书中可呼应）

- 优秀作品纳入**自然资源领域 AI 场景项目储备库**，优先全区试点
- 优秀作品纳入**自然资源系统项目库**，依托"一张图"开展中试验证
- 依托**南 A 东盟谷**在广西落地转化
- 纳入《广西地理信息产业发展报告》，广西测绘地理信息大会集中展示

## 十、风险提示

- ⚠️ **时间极紧**：9-15 截止，务必 9-14 前完成全部材料。
- ⚠️ **盖章流程**：基本信息表与责任声明需单位盖章，**提前走流程**，不要卡在最后一天。
- ⚠️ **数据合规**：不得涉及中国（含港澳台）及其他国家的秘密、个人信息和其他敏感信息（责任声明第 4 条）。
- ⚠️ **地图合规**：涉及"问题地图"风险，底图与行政界线必须使用合规来源。
