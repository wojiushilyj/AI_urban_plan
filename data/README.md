## 坐标系约定（见 README.md §4）
- 存储：**EPSG:4490**（CGCS2000 地理坐标）
- 量算：**EPSG:4525**（CGCS2000 3 度带 zone 37，CM 111E，桂林临桂区适用）

## 处理与属性说明

- 原始 `.shp` 中仅「永久基本农田」「生态保护红线」「临桂合并工业用地0910」「高速出入口」
  「货运场站用地」自带 `.prj`（`EPSG:4525`）；其余缺失 `.prj`，经坐标范围校验后统一补声明为 `EPSG:4525`。
- **2026-09-10 第二批（工业0910）**：新增独立图层 `current-industrial-land`（临桂现状工业用地），
  《临桂合并工业用地0910》684 图斑，覆盖临桂全区（109.88–110.33°E / 24.86–25.65°N），
  含三调地类（DLBM/DLMC）、坐落单位、企业名称、行业代码/名称、产值等属性，面积 2079.5 ha。
  与既有的 `industrial-land`（总规工业用地，215 图斑，1482.3 ha，无业务属性）**并存**，不替换。
- **「交通设施」大类**：道路路网（含铁路）、高速出入口、货运场站用地。这三者语义上不属于
  原 4 大类，故单独成类，不做强行归类。
- **「市政设施」大类（2026-09-11）**：`municipal-land`（工业配套市政用地）81 图斑（源 82，
  剔 1 条空几何），源 82 条含 1 条录入异常值「1303供电用电」。覆盖 7 个国标用地类别——
  1301 供水（11）、1302 排水（20）、1303 供电（38）、1304 供燃气（9）、1306 通信（2）、
  1307 邮政（1）、1311 水工设施（1）；`等级` 市/区级，`状态` 规划 42 / 现状 40（在库 40/41）。
  属工程性市政基础设施，与「服务与设施」（生产性服务业 + 文保）性质不同，单独成类。
- **「现状建设」大类（2026-09-11）**：`current-building`（现状建筑分布）7851 个建筑轮廓面，
  占地 634.6 ha，含 `区域`（苏桥 2742 / 秧塘 1957 / 乐和 1362 / 两江 898 / 大圆盘 892）与
  `层数`（1 层 3830 / 2 层 3027 / 3 层 994）。建筑轮廓不是"用地"，与产业用地的口径不同，单独成类。
- 属性裁剪：各图层按白名单保留业务字段，剔除 ArcGIS 内部字段（OBJECTID / Shape_Length / Shape_Area）
  与全空列；前端 GeoJSON 坐标取整至 1e-6 度（约 0.11 m）以压缩体积。
- 预处理产物：`processed/layers.gpkg`（GeoPackage/SQLite，EPSG:4490）+ `processed/geojson/*.geojson`
  + `frontend/public/data/layers/*.geojson`（EPSG:4326，前端加载）。
